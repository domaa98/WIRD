# وِرد | Wird — "اجعل لك وردًا من القرآن"
> **Your Quran, Your Time**

منصة ويب رقمية عربية هادئة ومجانية تهدف إلى مساعدة المسلمين في جميع أنحاء العالم على تلاوة القرآن الكريم بانتظام، وتخطيط ختمة واقعية وميسرة، وتتبع إنجاز القراءة، والمحافظة على عادة يومية مستدامة مع كتاب الله دون إعلانات ودون تتبع وبأعلى درجات الخصوصية.

---

## المبادئ الجوهرية (Core Principles)

- **مجاني للأبد وبلا إعلانات:** لا اشتراكات ولا نوافذ منبثقة أو بنرات تجارية.
- **الخصوصية أولاً (Local-First):** قراءة القرآن وتخطيط الختمة لا يتطلبان إنشاء حساب أو تسجيل دخول. تُحفظ خططك ومواضع قراءتك محلياً في متصفحك (`localStorage`).
- **مرونة بلا لوم أو ذنب:** عند فوات يوم أو انشغالك، لن تفقد ما أنجزته؛ بل يمكنك بضغطة زر إعادة جدولة الأيام المتبقية انطلاقاً من موضع وقوفك الفعلي.
- **نص قرآني موثق بالرسم العثماني:** نص معتمد من مشروع تنزيل العالمي (`Tanzil.net`) برواية حفص عن عاصم وفق العد الكوفي (6,236 آية).
- **واجهة عربية أصيلة (RTL-First):** خطوط عربية واضحة ومقروءة، ودعم كامل للوضع الداكن (Dark Mode) وتوافق مع الهواتف الذكية والأجهزة اللوحية والحواسيب.

---

## البنية التقنية (Tech Stack)

- **إطار العمل:** Next.js 14 (App Router)
- **لغة البرمجة:** TypeScript (Strict Mode)
- **التصميم والأنماط:** Tailwind CSS (Emerald & Deep Green & Warm Ivory palette)
- **الأيقونات:** Lucide React
- **التحقق من البيانات:** Zod
- **محرك الاختبارات:** Vitest
- **التخزين المحلي:** LocalStorage مع معالجة آمنة للأخطاء وترقية المخطط (Schema Migration) والتصدير/الاستيراد عبر ملفات JSON.

## التشغيل والتطوير المحلي (Quick Start)

### المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org) (الإصدار 18 أو أحدث)
- مدير الحزم `npm` (مرفق مع Node.js)

### خطوات التشغيل
1. استنساخ المستودع والانتقال للمجلد:
   ```bash
   cd WIRD
   ```

2. تثبيت الحزم:
   ```bash
   npm install
   ```

3. تشغيل خادم التطوير المحلي:
   ```bash
   npm run dev
   ```
   افتح المتصفح على: `http://localhost:3000`

4. تشغيل الاختبارات الآلية (Unit Tests):
   ```bash
   npm test
   ```

5. بناء نسخة الإنتاج (Production Build):
   ```bash
   npm run build
   npm start
   ```

## عملية استيراد وتوثيق بيانات القرآن (Data Provenance & Import)

يحتوي المستودع على سكريبت مؤتمت للتحقق من سلامة النص القرآني واستيراده:
```bash
node scripts/import-quran.mjs
```

### معايير التدقيق الإلزامية:
- التأكد من اكتمال 114 سورة بالترتيب العثماني المعتمد.
- مطابقة إجمالي الآيات بدقة للعد الكوفي: **6,236 آية**.
- تسلسل أرقام الآيات داخل كل سورة من 1 إلى N دون أي انقطاع أو تكرار.
- تعيين حدود الصفحات (604 صفحات) وحدود الأجزاء (30 جزءاً).
- الاحتفاظ ببيانات الترخيص (Creative Commons Attribution 3.0 Unported) ومصدر البيانات تنزيل (`Tanzil.net`).

## إدارة النسخ الاحتياطي والبيانات الشخصية

- **تصدير نسخة احتياطية:** من صفحة "تقدمي"، اضغط على "تصدير نسخة احتياطية" لتحميل ملف `JSON` يحتوي على خطتك ومواضع قراءتك وإشاراتك المرجعية وملاحظاتك.
- **استرجاع البيانات:** يمكنك رفع ملف النسخة الاحتياطية على أي جهاز آخر، ويتم تدقيق هيكل البيانات بدقة قبل تطبيقها.
- **مسح البيانات:** يمكنك في أي وقت مسح كافة السجلات من المتصفح عبر زر "مسح البيانات" بعد تأكيد صريح.
